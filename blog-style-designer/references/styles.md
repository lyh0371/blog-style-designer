# 风格库 · 五种博客风格定义

每种风格给出：气质描述、配色 tokens、字体、形态细节、组件特征。第 1 轮的 5 个迷你首页、第 2 轮的配色变体、第 4 轮的高保真页都必须严格按本文件渲染。

## 风格 1 · 暖纸书卷风（基准站：book.oiloil.org · 2026-11 浏览器实测）

**气质**：出版物式的「纸上阅读」体验，但形态是**书架**而非列表——每篇文章是一本书（有封面、章节号、作者署名），首页是摆满书封的书架。温暖、精致、耐读。

> ⚠️ **基准锁定**：用户明确要求选择此风格时必须与基准站保持一致。以下参数全部实测自该站（CSS + 浏览器截图），结构与色彩均不得偏离。该风格参与「实现步」时，3 种实现只能在基准语言内变化（浅色/深色、密度、区块顺序），不得引入新形态。

**配色 tokens（浅色）**：

| 用途 | 变量建议 | 色值 |
|---|---|---|
| 纸底色 | `--blog-paper` | `#faf8f4` |
| 墨色（主文字） | `--blog-ink` | `#262421` |
| 卡片面 | `--blog-surface` | `#fffefc` |
| 分割线 | `--blog-line` | `#ebe3d3` |
| 琥珀金（强调/主 CTA） | `--blog-accent` | `#c8a24b` |
| 琥珀金亮 | `--blog-accent-bright` | `#d8ad4e` |
| 琥珀金浅底 | `--blog-accent-soft` | `#f7df94` |
| 铁锈红（NEW 标/点缀） | `--blog-rust` | `#8f3c29` |
| 金棕（次要文字） | `--blog-gold-dim` | `#a5824c` / `#7d602c` |

**配色 tokens（深色，可选）**：paper `#161412`、ink `#ece5d8`、surface `#24201c`、amber-soft `#3a2f1b`。

**字体**：
- UI/无衬线：`Plus Jakarta Sans, Inter, MiSans, HarmonyOS Sans SC, Noto Sans SC, PingFang SC`
- 正文阅读（衬线）：`Source Han Serif SC / Noto Serif SC / Songti SC`
- 标题点缀：`Georgia, Noto Serif SC, serif`
- 代码/页脚小字：`ui-monospace, SF Mono, Menlo, monospace`

**首页布局结构（实测，必须遵循）**：
1. **顶部导航栏**（sticky）：左 = 圆形吉祥物 logo + 粗体站名 + 灰色域名小徽章；中 = 导航项（当前项琥珀色字 + 琥珀下划线）；右 = 圆形明暗切换按钮 + 白底描边按钮（如「投稿」）+ 文字「登录」+ **琥珀渐变胶囊主按钮**（如「订阅 Pro」，`#c8a24b→#d8ad4e` 渐变）。
2. **页面背景**：暖米白 + **淡网格纸纹理**（graph paper 细格线，透明度约 3-4%）——这是此前遗漏的关键细节。
3. **分区结构**：每个内容分区 = 左侧大号粗体标题（如「实战指南」）+ 下一行灰色一句副标题；右侧 =「共 N 篇」灰底胶囊 + 「查看全部 →」链接。
4. **书封卡片网格**（4 列）：每篇内容一张**竖版书封**（约 3:4 比例，各自不同的纯色底 + 印刷风几何装饰图形 + 书名排版，如米色波浪纹/砖红/藏蓝/芥末黄）；封面下方三行：状态标签行（`NEW` 铁锈红胶囊 + `第 N 章` 琥珀字 + `PRO` 黄胶囊）→ 粗体标题（最多两行）→ 作者胶囊（小圆头像 + 名字，灰底描边）。
5. **白卡区块**（如模型推荐）：2 列白色圆角大卡，内含彩色图标 + 名称 + 琥珀小标签 + 衬线引号引文 + 「典型场景 / 注意点」两列小字（列间细分割线）。
6. **页脚**：极简一行居中（`✦ 站名 · 一句话定位`）。

**形态细节**：圆角中等（8-14px），阴影极轻；书封内装饰用细线几何图形（波纹、网格、星轨）；标签胶囊大量使用（NEW/PRO/共 N 篇/作者）；强调色集中在导航当前态、主 CTA、章节号上。

**组件特征**：作者署名是固定元素（每张内容卡都有作者胶囊）；阅读页提供衬线/无衬线、字号、明暗三组阅读器偏好。

## 风格 2 · Bento 玻璃卡片风（参考站：mumingfang.com）

**气质**：「看这个人」的个人主页美学，像一张摊开的桌面或手账。轻松、年轻、生活化，每个模块是一个生活切片。适合展示型首页 + 简洁文章页的混合形态；纯长文阅读体验弱于纸墨系。

**配色**：
- 极光渐变底：`linear-gradient(120deg, #baf2dd 0%, #c4e6fb 45%, #f2d9ee 80%, #e8def5 100%)`（薄荷绿→淡天蓝→浅粉紫→淡薰衣草，柔和过渡）
- 玻璃卡片面：`rgba(255,255,255,.62)` + `backdrop-filter: blur(12px)`
- 玻璃内嵌面板：`rgba(255,255,255,.75)`
- 文字：主 `#262626`、次级 `#4c5568`、弱化 `#99a1af`
- 点缀色：天蓝 `#6cbcff`、柠檬黄 `#fac800`、橙 `#f99c00`
- 深色模式：底 `#282828`（深灰非纯黑），卡片同为白玻璃逻辑

**字体**：全局无衬线（系统栈 `ui-sans-serif / PingFang SC`），标题 700-800 字重；emoji 承担图标职能。

**形态细节**：
- **Bento 拼贴网格**：大小不一的卡片（如 `1.35fr 1fr` 双列），大卡放主打内容，小卡放生活切片
- 卡片圆角大：`20px`；内嵌面板 `14px`
- 卡片阴影：`0 8px 24px rgba(60,80,100,.10)`（蓝灰调、柔和）
- **底部悬浮 Dock 导航**：胶囊形 `border-radius:999px`，白玻璃底，阴影更重（`0 10px 28px rgba(60,80,100,.18)`），图标间距均匀，当前项放大强调
- 趣味拟物：emoji 卡片图标、图钉 📌 贴纸、倾斜堆叠卡、渐变色块图标容器（`14px` 圆角方块）

**组件特征**：头部 = 圆形头像（彩边）+ 名字 + 一句 slogan；卡片标题 = emoji + 粗体中文；文章卡含标题/摘要/日期/阅读时长；页脚极短居中。

## 风格 3 · IDE 编辑器风（用户从三个变体中选定：VS Code 拟物方向）

**气质**：博客即编辑器。整个站点拟物成一个代码编辑器（VS Code / Catppuccin Mocha 色），文章是「打开的文件」，博客是「工程」。工程趣味最强，写给开发者看。

**配色（Catppuccin Mocha 系）**：
- 编辑区底 `#1e1e2e`、侧栏/标题栏 `#181825`、标签栏/状态栏 `#11111b`、边框 `#313244`
- 主文字 `#cdd6f4`、次级 `#9399b2`、弱化 `#6c7086` / `#45475a`（行号）
- 语法色：红 `#f38ba8`（标题 #/##、未保存点）、蓝 `#89b4fa`（H2、活动标签顶线）、绿 `#a6e3a1`（任务勾选、当前文件、`✓ main`）、桃 `#fab387`（引用行）、黄 `#f9e2af`
- 窗口圆点：`#f38ba8 / #f9e2af / #a6e3a1`

**字体**：全局等宽 `Consolas, JetBrains Mono, monospace`，字号 12px 基准；区块标签（EXPLORER）大字距。

**形态细节**：
- **三层 chrome**：标题栏（三圆点 + 编辑器名「XX — Visual Blog Studio」）→ 左侧文件树侧栏（`posts/`、`drafts/`、`config.toml`，当前文件绿色 + 红色未保存点）→ 主编辑区（标签页 + 行号 + 内容）
- **标签页**：活动标签浅底 + 顶部 2px 蓝色顶线；其余暗灰
- **内容用 Markdown 语法高亮呈现**：`#` 红色 + 标题加粗大字号、列表 `- [x]` 绿色勾、引用 `>` 桃色、日期灰色后缀
- **状态栏**：`✓ main · Markdown · UTF-8` 左 / `Ln 10, Col 14` 右，10px 小字
- 三栏 grid：`180px 1fr`；最小高度撑起编辑区

**组件特征**：导航隐藏在文件树里（文章=文件）；「关于」= about.md；「订阅」= config.toml 或侧栏入口；页脚由状态栏承担。

## 风格 4 · 瑞士极简风

**气质**：国际主义排版。纯白、网格、编号、几何，用克制到极致的方式传达信息。

**配色**：底 `#FFFFFF`、墨 `#0A0A0A`、次级灰 `#777777 / #AAAAAA`、强调瑞士红 `#E30613`（仅小面积）。
**字体**：全局无衬线（`Helvetica Neue / PingFang SC`），标题 800 字重、大号、严格左对齐。
**形态**：编号体系（01/02/03，编号用强调色）、`60px 1fr auto` 三列网格列表、1px 黑色粗分割 + 1px 浅灰分割、logo 后接红色句点。无卡片、无阴影、无圆角。

## 风格 5 · 复古海报风（用户从三个变体中选定：Mid-century 印刷海报方向）

**气质**：Mid-century 印刷海报。大色块、粗描边、硬阴影、网点纸纹理，复古感来自五六十年代印刷海报而非旧报纸。明快、有劲儿、复古但不陈旧。

**配色**：
- 纸底：`#f7ead0`（奶油米色）+ 网点纹理 `radial-gradient(rgba(46,42,36,.055) 1px, transparent 1px)`，`background-size: 9px 9px`
- 墨色（主文字/描边）：`#2e2a24`
- 大色块：芥末黄 `#e3a72f`、砖橙 `#c65f3d`、墨青 `#3f7d72`（反白文字）
- 深色模式：可选，底改深褐 `#2e2a24` 系、色块降饱和

**字体**：全局粗无衬线（`PingFang SC`，标题 900 字重），大字距（letter-spacing 2-6px）；无衬线的"印刷海报感"是本风格标志，**不用衬线**。

**形态细节**：
- **粗描边卡片**：`border: 3px solid #2e2a24` + **硬阴影** `box-shadow: 6px 6px 0 #2e2a24`（offset 零模糊，印刷套色感）——这是本风格最核心的辨识点
- **网点纸纹理**铺满背景
- 圆形徽章（如「NEW 刊」）：`border: 3px solid` + 砖橙底反白
- 头部：左侧黑底标签（EST. 2026）+ 居中大字距博客名 + 右侧圆形徽章
- 导航条：上下 3px 墨色粗线夹住，当前项用芥末黄色块反衬
- 卡片布局：`1.4fr 1fr` 双列（头条大色块卡 + 侧栏小卡堆叠）
- 页脚：左右色块标签（慢印出版 / © 2026）+ 中间 ★ 星号装饰行

**组件特征**：卡片标题 emoji-free，用「头 条 · FEATURE」式字距标签；日期行「2026.03.14 ✦ 阅读 12 MIN」带星号分隔；所有文字 700-900 字重。

## 第 2 轮配色变体的生成规则

- 选定某风格后，保留其字体与形态骨架不变，仅换色彩层（底/墨/强调/次级），生成 5 组。
- 每组配一句气质名（如「黄昏书房」「雨夜电台」「清晨报纸」）。
- 若风格 1：第 1 组必须是基准配色（见上表），其余 4 组做气质变体（如琥珀→陶土橙、琥珀→墨绿、深色模式反向等）。
